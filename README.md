# 💻 Tarea Desafío - Fundamentos y Funciones en JavaScript

Este proyecto representa el uso de **tipos de datos en JavaScript**, aplicando lo aprendido en clase con información real extraída de una página de producto de Amazon (teclado SteelSeries Apex 3 TKL). El código contiene variables, funciones y estructuras de datos como objetos y arrays, demostrando los fundamentos esenciales de la programación.
📌 Temas aplicados
- Variables
- Tipos de datos primitivos:
  - `string`
  - `number`
  - `boolean`
  - `null`
  - `undefined`
  - `symbol`
  - `bigint`
- Tipos de datos no primitivos:
  - `array`
  - `object`
  - `function`
- Uso de `console.log()`
- Organización de información estructurada
- Funciones personalizadas
## 🧾 Descripción del proyecto

El código define información detallada sobre un teclado para videojuegos usando diversos tipos de datos en JavaScript. Incluye características técnicas, compatibilidad, disponibilidad, descuentos, y una función que imprime un resumen en consola.
